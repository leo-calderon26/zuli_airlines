# zuli_airlines - Sistema de Reservas Aéreas

## 1. Resumen o Descripcion
Este proyecto consiste en crear una plataforma de software para gestionar la operación de una aerolínea, la cual debe estar integrada con plataformas de otras aerolíneas para poder ofrecer conexiones de modo que los viajeros puedan tramitar todo un itinerario de viaje desde un solo sitio web.
